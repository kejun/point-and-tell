# 截图卡片、完整分段与真实语音时间

## 生成与编辑

- 新录制先按用户的标记截图、已保存的画笔会话建立卡片，每个事件对应一张。多笔绘制属于同一会话；取消不生成。ID 来自截图事件，重复完成回调不重复建卡，相同时间的不同事件分别保留。
- 保存截图时同时持久化卡片；无需等待音频检查或 ASR。无语音、失败、取消及缺少时间戳不会删除图片卡片。
- 完成录制、转写/重试、打开和导出均不自动抽取视频帧。卡片面板保留“提取截图”，取出的图片只替换明确选中的卡片，不另外生成卡片；图片和 manifest 保存失败时保持原选择。
- 文字自动保存，讲解时间在结束编辑、切卡或保存时校验。重复的“保存时间”按钮已移除；⌘S 仍可重试保存。文字保存失败会阻止后续切卡/开始处理，直到保存成功。
- 配图来源区分录制标记、画笔、录后手动提取。旧 frame 视为历史普通截图，保留文件和既有选择，但不拿来新建自动卡片。
- v0.5.1 的“分段详情”显示截图与画笔时间、原始语音范围和分段依据。默认显示“已按卡片分段 · 可直接编辑”，不再因分界拿不准拒绝分配文字。
- 文字框下方的“首句移到上一张 / 末句移到下一张”移动边界附近的一句（如果分界落在句内，则移动该片段），保持全文顺序。两张卡片一起保存；写入失败不改变卡片或选择。首尾、空卡和忙碌状态下禁用不适用的操作。
- “原始转写”保留所有源文字与供应商时间；没有时间戳的文字也会进入卡片。没有录制截图时保留原始转写，不擅自创建图片；可从“文件 → 原始转写…”进入。

## 关联规则与时间链

1. 截图采集前后分别读取 RecordingEngine 的有效媒体时间，并保存两次观测与中值截图时间，均为录制坐标。v0.5.0 的时钟使用同一 AVCaptureMovieFileOutput 样本边界的 PTS，修正原始 recordedDuration 与成片 edit list 的偏差，见 [暂停计时说明](PAUSE-RECORDING.md)。CGWindowList 截图本身没有精确视频帧 PTS，详情明确显示此限制。画笔会话开始时间另存 annotationStartSeconds，保存时间放在 endTimestamp，均不替换冻结图的时间。
2. AudioChunker 沿用实际 MOV 音轨 PTS，保留音轨起始偏移，WAV 分片 startSeconds 是录制坐标。供应商句/词毫秒除以 1000，再加一次分片起点；不再叠加墙钟或音轨偏移。
3. 请求继续使用指定的 qwen-audio-3.0-asr-flash 与原 MAAS 端点；≥60 秒使用 SSE 获取已完成句，较短响应兼容 JSON。解析器仍拒绝未完成/截断的 SSE 与无效时间；完整源文字缺少时间时会保留，供人工校对。
4. 按截图时刻及原事件顺序建立 K 张卡片。对原始转写进行固定 K 段的连续分割，每个原文片段只分配一次，首尾完整覆盖。文本量足够时每张卡片有内容；确实不足时保留空卡供补充，不复制或编造文字。相同截图时间、画笔区间重叠、距离超过 12 秒均不再造成拒绝分配。
5. 在真实词边界或文字边界建立候选：优先完整句子，再考虑原 ASR 句边界、逗号/分句、空格，最后才在无标点中文的字符边界切分；拉丁单词和组合 emoji 保持完整。时间与停顿是软评分，弱长度项只打破接近的平局，不强制等长。局部可加的分配/分界代价使用 O(KN) 动态规划一次选择全部 K−1 个分界，N 为文字单位数；没有置信度拒绝门槛，不调用模型或上传新数据。
   - 词时间完整且精确覆盖源句时保留供应商词范围；其他情况保留源句时间。拆开只有句时间的文字时，各片段引用原句范围，不均分时长，不声称获得新的词时间。缺少时间的片段继续保留，时间为空。
   - 每个自动片段持久化原文、源转写 ID 和 UTF-16 起止位置，支持验证源文字无遗漏、重复或乱序。界面可以在不同 ASR 句之间加入换行；源片段本身逐字保留。
   - 开头/结尾移动优先使用这些来源片段；自由改写后的内容按当前文字移动，不搬回旧转写。显式修改过的卡片时间继续保留。
6. 重试仅更新未改动的自动内容；用户文字、讲解时间和配图选择受到保护。删除按截图事件 ID 记住，仍保留该事件的时间分界，避免把已删讲解挤到相邻卡片。
7. 编辑器、HTML、Markdown 共用保存后的卡片数组。导出不会另做自动成卡或再次拆分截图卡片。

旧项目首次打开采用截图模式时，已有卡片保持原文、时间、图片和顺序。旧删除记录无法可靠反推每张截图时，保守保留删除决定，不从未表示的旧截图恢复卡片。已有截图模式项目重新打开时只重建未编辑的自动卡片；无需重传音频或再次调用 ASR。项目仍为 schema 1，新增片段来源元数据均为可选字段；保留旧项目备份以便旧版本回退。

## 回归与验证边界

完整覆盖约束适用于自动初稿；用户改写、删除卡片属于明确整理决定，重试不会为了凑齐原文而覆盖或恢复这些内容。

核心回归覆盖：两次画笔和一次标记、一整段 ASR、词/句/无时间、相同时间独立事件、超过六张截图、真实停顿、跨分片与非零偏移、编辑和删除后重试、历史项目、无主动截图，以及保存/重开/导出一致性，以及旧歧义占位迁移、Unicode 精确保留、无标点长句、全量归属、长转写与相邻移动。

原生 UI fixture 使用本地合成图片和 stub 转写，不上传音频，检查即时保存卡片、不自动抽帧、手动取图只更新当前卡片、磁盘写入失败时保留编辑。原有本地媒体 fixture 继续检查非零音轨 PTS、分片起点和音频缺口/重叠。

仍需在目标 Mac 验收先讲后画、绘制中讲解和先画后讲的实际样本；检查截图、MOV 帧和语音事件的可见偏差。5 fps/10 fps 分别约 200/100 毫秒一帧，捕获缓冲还可能增加偏差。存储毫秒不意味着毫秒级采集或识别精度。本次没有真实付费 ASR 请求，没有确认此前特定录制的固定时间漂移根因。

参考：[Qwen 模型请求示例](https://www.qianwenai.com/models/qwen-audio-3.0-asr-flash)、[供应商 HTTP/SSE 时间字段](https://help.aliyun.com/en/model-studio/fun-asr-flash-recorded-speech-recognition-http-api)。
